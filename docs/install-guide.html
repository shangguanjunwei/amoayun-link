常见问题

安装过程中遇到问题先看这里
安装完成后右下角没有 Amoayun Link

先确认插件已经「立即启用」，然后完全退出 DeepSeek Harness 并重新打开。只关闭窗口或刷新页面不一定能加载 Host 插件。

添加插件时提示找不到包

确认包名完整填写为 @amoayun/dsh-amoayun-link-plugin。如果仍然失败，检查网络和插件页面显示的版本信息。

扫码后账号一直显示等待扫码

重新点击扫码登录，使用 vx 扫描最新的二维码并确认授权。二维码过期后需要重新生成。

联系人发消息没有进入 Agent

检查账号是否在线；如果开启了「仅允许已授权联系人」，确认对方已经授权，或者输入了正确的 6 位配对码。

插件安装成功但功能没有变化

必须重启 DSH 桌面端。安装和启用只是写入插件，重启后 Host 才会完整加载插件。

截图里的二维码和路径为什么被遮挡

这些内容包含账号、登录或联系人信息。教程只保留操作界面，二维码和路径已经做隐私处理。
